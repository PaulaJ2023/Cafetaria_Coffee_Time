Escreva qualquer coisa aqui que possa ajudar no projeto. Dicas, lembretes e anotaçãos podem ser adicionados!

🛒 Parte do Cliente (loja.js)
Login Inteligente: Identifica se é um cliente comum ou se é a Duda (Administradora), redirecionando-a direto para o painel de controle.

Cadastro com Validação: Criação de conta que avisa o usuário se as senhas digitadas não forem iguais.

Carrinho de Compras: Soma os valores dos produtos automaticamente, calcula o total e permite remover itens com um clique.

Formulário Adaptável: Esconde ou mostra o campo de endereço dependendo se o cliente escolhe "Delivery" ou "Retirada".

Painel de Acessibilidade (UI/IHC): Botões para aumentar/diminuir fonte, ativar alto contraste, inverter cores e links sublinhados para melhor leitura.

Modo Escuro: Salva a preferência de tema escuro no navegador para que o site continue escuro mesmo se a página for atualizada.


🛠️ Painel do Administrador (admin.js)
Listagem e Filtro de Pedidos: Mostra todos os pedidos vindos da loja e permite filtrá-los por status (Pendente, Preparo, A Caminho, Finalizado).

Controle de Progresso: Botões para avançar o status do pedido à medida que o café fica pronto ou excluir o histórico da tabela.

Dashboard de Métricas: Atualiza sozinho no topo da tela o total de pedidos, o faturamento em R$ e quantas entregas estão pendentes.

Cadastro de Equipe: Registro de novos funcionários separando por cargos (Barista, Gerente, Estagiário) com ícones e cores diferentes para cada um.


☕ Integração com o Java
Gerador de Token (Exportação): Botões especiais que transformam os dados do último pedido ou do último funcionário em uma linha de texto organizada (ex: Nome;Email;Cargo) para você copiar e colar direto no seu sistema Java da A3.
